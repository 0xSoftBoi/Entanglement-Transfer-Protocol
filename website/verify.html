3 · Verify

Optional: a notary URL enables the post-quantum signature checks (only the public receipt is sent — never your file).

    What do these checks mean? In-browser: the sealed file's SHA3-256 must match the notarized manifest, and the manifest must reconstruct the log root via its RFC-6962 inclusion proof. Via notary (or the CLI): the operator's ML-DSA-65 signature over that root, and the capturing device's signature if present. For a fully offline, fully post-quantum verification — including operator/device key pinning — use etp-custody verify.
